1. **Comando:**
   - `nc saturn.picoctf.net 56688` establece una conexión a un servidor (en este caso, `saturn.picoctf.net`) en el puerto `56688` usando `netcat` (nc). Esto permite al usuario interactuar con el servidor.

2. **Interacción con el servidor:**
   - El servidor envía un mensaje que solicita que se haga un hash MD5 del texto entre comillas, excluyendo las comillas. 
   - La primera petición es para la cadena `'killer whales'`. El usuario responde con el hash MD5 correspondiente (`7339bcecf2fe2c278ef6e90586669fbc`) y el servidor confirma que la respuesta es correcta.

   - Finalmente, se solicita de nuevo el hash para `'killer whales'`, y se confirma que la respuesta es correcta.

3. **Salida final:**
   - Después de varias interacciones exitosas, el servidor devuelve la bandera `picoCTF{🏁}`, lo que indica que el usuario ha completado la tarea correctamente.

### Conversión de cadenas de texto a MD5:

Para conocer la cadena de texto en MD5 en otra ventana de terminal, se utilizó la herramienta `md5sum` de la siguiente manera:

#### Comando básico:

```bash
echo -n "tu_cadena_de_texto" | md5sum
```

### Explicación de los comandos:

1. **`echo -n "tu_cadena_de_texto"`:**
   - El comando `echo` imprime el texto especificado. El argumento `-n` evita que se agregue una nueva línea al final del texto, lo cual es importante porque cualquier nueva línea podría cambiar el resultado del hash.

2. **`| md5sum`:**
   - El símbolo `|` (pipe) se usa para tomar la salida del comando anterior (`echo`) y pasarla como entrada al siguiente comando (`md5sum`).
   - `md5sum` genera el hash MD5 de la cadena de texto que recibe. La salida consistirá en el hash seguido de un guion (que indica que la entrada vino de la terminal y no de un archivo).

### Ejemplo:

Para convertir el string `"hola"` a MD5, el comando sería:

```bash
echo -n "hola" | md5sum
```

Esto generaría una salida similar a:

```bash
4d186321c1a7f0f354b297e8914ab240  -
```

- La parte antes del guion (`4d186321c1a7f0f354b297e8914ab240`) es el hash MD5 de la cadena `"hola"`.

### Resumen:

La terminal muestra la interacción del usuario con un servidor para obtener hashes MD5 de cadenas de texto específicas. Se utilizaron comandos en otra ventana para calcular estos hashes utilizando `md5sum`, lo que permitió al usuario proporcionar respuestas correctas y, por lo tanto, recibir la bandera al finalizar las tareas.
