# Glitch-cat

```bash
┌──(kalilinux)-[~/picoCTF]
└─$ nc saturn.picoctf.net <int>
'picoCTF{gl17ch_m3_n07_' + chr(0x61) + chr(0x34) + chr(0x33) + chr(0x39) + chr(0x32) + chr(0x64) + chr(0x32) + chr(0x65) + '}'

┌──(kalilinux)-[~/picoCTF]
└─$ python -c "print('picoCTF{gl17ch_m3_n07_' + chr(0x61) + chr(0x34) + chr(0x33) + chr(0x39) + chr(0x32) + chr(0x64) + chr(0x32) + chr(0x65) + '}')" 
picoCTF{🏁}

```

Este desafío de **picoCTF** parece involucrar la conversión de caracteres hexadecimal a ASCII para revelar una bandera, además de utilizar un servidor remoto (a través de `nc`, que es el comando `netcat`). Vamos a desglosarlo paso a paso.

### 1. **Comando `nc saturn.picoctf.net <int>`:**
   - `nc` (abreviatura de `netcat`) se utiliza para interactuar con servidores de red. En este caso, te estás conectando a un servidor remoto en `saturn.picoctf.net` en el puerto `<int>`.
   - El servidor probablemente te devuelve la bandera parcial: `'picoCTF{gl17ch_m3_n07_'`, seguida de una serie de valores hexadecimales que debes convertir en caracteres.

### 2. **Serie de `chr()` y valores hexadecimales:**
   El servidor devuelve una cadena que incluye valores hexadecimales. Aquí están los valores y su explicación:

   - `chr(0x61)` = `'a'`
   - `chr(0x34)` = `'4'`
   - `chr(0x33)` = `'3'`
   - `chr(0x39)` = `'9'`
   - `chr(0x32)` = `'2'`
   - `chr(0x64)` = `'d'`
   - `chr(0x32)` = `'2'`
   - `chr(0x65)` = `'e'`

   Estos caracteres se concatenan con la bandera parcial `'picoCTF{gl17ch_m3_n07_'` para formar la bandera completa.

### 3. **Comando Python para imprimir la bandera:**
   ```bash
   python -c "print('picoCTF{gl17ch_m3_n07_' + chr(0x61) + chr(0x34) + chr(0x33) + chr(0x39) + chr(0x32) + chr(0x64) + chr(0x32) + chr(0x65) + '}')"
   ```
   - Este comando utiliza Python para imprimir la bandera completa.
   - El uso de `chr()` convierte los valores hexadecimales en sus correspondientes caracteres ASCII.
   - El resultado es: `picoCTF{gl17ch_m3_n07_a432d2e}`.

### 4. **Salida:**
   Al ejecutar este comando en tu terminal, obtienes la bandera completa, que es:
   ```bash
   picoCTF{gl17ch_m3_n07_a432d2e}
   ```
